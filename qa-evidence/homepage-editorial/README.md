# 홈페이지 현재 검증 상태

참조: https://open-design.ai/showcase-previews/community-open-design-landing/

## 적용과 차이
- 참조의 편집형 메타 행·로마 숫자 구분선·큰 제목·비대칭 제품 영역·둥근 버튼·기능 카드·큰 단계 숫자·대형 하단 워드마크를 적용했다.
- 베이지 종이 질감·코랄·조각상 이미지는 현재 흰 표면·그린·Pretendard·실제 PDF 화면으로 바꿨다. 레퍼런스의 자동 이동 장식과 가상 후기·사용 통계는 사용하지 않는다.
- 한국어 제목과 본문은 현재 문구를 유지하고, 일본어 제목은 문자 단위 줄바꿈을 허용한다. 기존 JS·번역·법률 문서·CTA 경로는 재사용한다.

## 검증
- `preview.html`은 `../../portable/homepage.html`을 같은 출처 iframe에서 실제 브라우저로 표시한다. 웹 폴더를 HTTP 서버 루트로 열고 이 검증 페이지에서 Run checks를 누른다. 뷰포트 폭은 360·390·768·1024·1440px, 언어는 ko·en·ja·de·da·nb·fi다.
- 390·1440px에서는 모든 언어의 6개 안내 경로·문서 언어·선택기 동기화·헤딩 포커스·법률 문서 표시를 검사한다. 홈은 모든 폭과 언어에서 넘침·이미지·제목 너비를 검사한다. FAQ·메뉴·Escape 포커스·잘못된 경로·CTA 경로도 검사했다. 결과: 462개 검사 통과, 브라우저 JS 오류 0건.
- `desktop-1440.png`·`tablet-768.png`·`mobile-390.png`는 실제 iframe 뷰포트를 표시한 브라우저 화면이다. 화면이 작은 경우 데스크톱 뷰포트는 전체 비례로 축소 표시한다.
- 타입 검사·린트(기존 PdfPage React 경고 있음)·전체 테스트 284개·디자인시스템·일반 빌드·portable 빌드 통과.
- 실제 Android/iOS 기기, file:// 실행, 공개 배포는 미검증이다. file://를 브라우저 도구로 여는 동작은 허용 프로토콜 제한으로 차단됐다.
