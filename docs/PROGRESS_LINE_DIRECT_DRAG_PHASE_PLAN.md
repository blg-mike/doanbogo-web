# 진행선·차트 행 인식 메모

## 선·스타일
- 페이지별 주선 1개·참고선 최대 2개. 새 주선은 전체 페이지 폭·두께 12·불투명도 40%, 두께 범위는 1~36이다. 저장된 스타일은 보존한다.
- 선 몸통·끝·마커를 직접 조작한다. 작업 개체보다 위에서 입력을 우선하고 실제 hit target 밖 도구 입력은 유지한다.
- 짧은 탭·450ms 롱프레스는 선 옆 스타일을 연다. 8px 초과 이동은 드래그이며 종료 후 스타일을 열지 않는다.
- 10색·두께·투명도와 주선 집중 강도 0~80%·띠 높이 1~30%를 제공한다. 새 집중 기본값은 22%·3%다.
- 슬라이더 한 조작은 실행 취소 한 단계다. 삭제 토스트는 실행 취소·닫기를 제공하고 5초 뒤 닫힌다.

## 차트 행 인식
- 주선의 `···`에서 영역을 지정하고 PDF·사진 원본만 Worker로 분석한다. 진행 상태·취소와 늦은 결과 차단을 유지한다.
- 검출 행의 중심·좌우를 보정하고 행 추가·삭제, 방향·카운터·시작 단, 이전/다음 미리보기 후 적용한다.
- 각 행의 실제 위치·폭을 저장하며 카운터 +/−·정확한 복원 이력과 연결한다. 첫 방향은 아래→위, 마지막 행에 머문다.
- 수동 이동·길이 조절은 따라가기를 중지하며 메뉴로 재개한다. 180도 회전은 추적하고 분석과 90·270도 차이면 따라가기를 중지한다.
- 행 좌표는 원본 정규화 좌표다. 저장·실행 취소·백업 검증의 기존 경로를 사용한다.
