# 진행선 구현 메모

## 현재 계약
- 페이지별 주선 1개·참고선 최대 2개, 모든 회전에서 화면 기준 수평.
- 새 주선: 페이지 전체 너비·두께 12. 스타일 두께 1~36.
- 몸통·양끝 핸들·마커 직접 조작. 짧은 탭·450ms 롱프레스는 선 옆 스타일, 8px 초과는 드래그.
- 승인 10색·투명도·주선 집중 설정을 사용한다. 집중 강도 0~80%, 띠 높이 1~30%.
- 단 간격·차트 범위·메인 카운터 연결을 저장하고 카운터 증감/되돌리기에 위치를 맞춘다.
- 원본 정규화 좌표·회전별 위치·저장된 스타일을 보존한다. 슬라이더 한 번 조작은 실행 취소 한 단계다.

## 수정 경로
`progressLines.ts` → `ProgressLineOverlay.tsx` → `Viewer.tsx`의 저장·카운터 연동. 타입·백업은 `types.ts`, `storage.ts`, `backup.ts`.

## 확인
탭/드래그 분리, 경계·회전·확대·두 영역, 집중 띠 이동, 카운터 간격·정확한 복원, 실행 취소·재진입·백업을 확인한다. 전체 UI 기준은 [DESIGN.md](../DESIGN.md).
