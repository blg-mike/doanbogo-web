# 워크스페이스 차트 만들기 Phase Plan

작성일: 2026-10-04 · 상태: 구현·자동 검사·portable HTML 빌드 완료. 브라우저에서 직접 여는 사용자 동작은 미확인.

## 실행 기준

별도 요청 전까지 프로젝트 실행과 사용자 동작 확인은 `doanbogo-web/portable/index.html`을 Chrome 또는 Edge에서 직접 여는 방식으로 한다. 소스 변경 후 `npm run build:portable`로 단일 HTML을 갱신한다. Vite 개발 진입점 `index.html`과 개발 서버는 기능 실행 기준이 아니다.

## 확정된 제품 결정

- 워크스페이스에서 PDF와 차트를 함께 검색·정렬·열고, 차트를 복사·이름 변경·삭제한다.
- 차트 생성은 간소화한다. 코바늘은 Free Form 안내를 거쳐 빈 편집기를 연다. 대바늘은 Colors·My Own Colors·원형뜨기·빈 차트를 고정하고 격자와 게이지를 설정한다.
- 대바늘 기본값은 20코 × 20단, 게이지 18코 × 24단 / 4인치다. 격자 한 변은 1~200이며, 단위는 inch 또는 cm다.
- 대바늘 색상은 최대 12개로 편집한다. 색상 변경은 그 색을 사용 중인 셀·기호에 반영한다.
- 코바늘 기본 기호는 사슬뜨기, 빼뜨기, 짧은뜨기, 긴뜨기, 한길긴뜨기, 두길긴뜨기다. 기호 모양은 [Craft Yarn Council 표준 차트 기호](https://www.craftyarncouncil.com/standards/crochet-chart-symbols)에 맞춘다. 기호는 자유 캔버스에서 개별 및 다중 선택, 이동·회전·크기 조절·색상 변경을 지원한다.
- 코바늘 레이어는 이름 변경, 순서 변경, 표시 전환, 잠금을 지원한다. 편집 이력은 Undo/Redo로 복원한다.
- PNG와 PDF는 보이는 차트 영역을 내보낸다. 격자 번호와 색상 표시는 차트 이미지에 포함하고 편집 도구와 선택 테두리는 제외한다.

## 구현 단계

1. **저장 및 워크스페이스:** IndexedDB v3 차트 저장소, 혼합 카드·검색·정렬, 생성 화면과 경로를 추가한다.
2. **대바늘 차트:** 격자·게이지 설정, 색상 팔레트, 색칠·지우개·영역 채우기·선택·복사·붙여넣기·반전을 구현한다.
3. **코바늘 Free Form:** 기호 배치·선택·이동·변형·복제·삭제와 레이어 편집을 구현한다.
4. **저장·백업·내보내기:** 자동 저장과 v4 백업/복원을 추가하고 이전 v1~v3 백업 호환을 유지한다. PNG와 PDF를 생성한다.
5. **검증:** 기존 PDF 흐름 회귀, 차트 왕복 저장, 백업 ID 충돌, 차트 출력과 portable 단일 HTML 빌드를 확인한다.

## 검증 기준

- 각 차트 유형을 생성해 편집한 후 워크스페이스에서 다시 열었을 때 상태가 보존된다.
- 격자 드래그 한 번은 Undo 한 번으로 되돌아가며, 채우기와 선택 변환 결과가 격자 경계에서 벗어나지 않는다.
- 코바늘 다중 선택·레이어 숨김·잠금·순서 변경이 화면과 내보내기에 반영되고 저장 후 복원된다.
- v1~v3 백업은 차트 없이 가져오고 v4 백업은 PDF 및 차트를 함께 복원한다. 차트 ID가 겹치면 가져온 차트에 새 ID를 부여한다.
- `npm run typecheck`, `npm run lint`, `npm test`(8개 통과), `npm run build:portable` 통과. Chrome/Edge에서 직접 여는 사용자 동작 확인은 portable 빌드 생성과 별도로 기록한다.

## 구현 상태

차트 저장소와 v4 백업, 혼합 워크스페이스, 생성 설정, 대바늘 격자 편집기, 코바늘 기호·레이어 편집기, Undo/Redo, PNG/PDF 내보내기를 구현했다. 테스트와 단일 HTML 빌드는 통과했다. 실행 도구의 `file://` 보안 제한 때문에 이번 변경의 Chrome/Edge 직접 열기 및 포인터 상호작용 검증은 완료하지 못했다.

## 첨부 참고 자료와 범위

`chart.md`와 화면 예시는 제품 흐름 및 에디터 참고 자료로 사용한다. 현재 웹 프로젝트의 React·IndexedDB·portable HTML 기반에 맞춰 적용하며 React Native·SQLite 제안은 사용하지 않는다. 이미지 자동 변환, AI, 계정 동기화, 협업, 추가 공예 종류는 이 기능 범위에 포함하지 않는다.
