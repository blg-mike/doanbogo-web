# 차트 구현 메모

## 현재 동작
- `/charts/new`에서 대바늘 색상 모눈 또는 코바늘 Free Form 기호 차트를 생성한다.
- 대바늘은 코·단 수와 게이지·cm/inch 설정으로 예상 크기를 계산한다. 색칠·지우개·채우기·선택·복사·반전을 제공한다.
- 코바늘은 기호 배치·다중 선택·이동·회전·크기 조절과 레이어 이름·순서·표시·잠금을 제공한다.
- 실 색상은 사용자 지정이며 저장·실행 취소·PNG/PDF 출력에 반영한다.
- 프로젝트 카드·검색·정렬과 .doanbogo 백업·복원에 차트를 함께 포함한다.

## 수정 경로
`ChartCreate.tsx`, `ChartEditor.tsx`, `charts.ts`, `storage.ts`, `backup.ts`, `Chart.css`.

## 확인
각 유형의 생성·편집·재진입, 스트로크 실행 취소, 선택 변환의 경계, 기호/레이어 복원, 백업 ID 충돌과 PNG/PDF 출력을 확인한다. 차트 내부 색상은 [디자인시스템](../design_system.md)의 실 색상 규칙을 따른다.
