# 웹 검증 메모

## 코드·생성
- [ ] 타입 검사·린트·관련/전체 테스트 결과 확인.
- [ ] 디자인시스템 검사, 일반 빌드·표준 portable 빌드.
- [ ] 생성 앱·홈페이지의 자산·진입 경로 확인.

## 작업 데이터
- [ ] PDF·사진·차트 추가, 편집, 재진입·복사·백업 왕복.
- [ ] 저장 실패·재시도·임시 저장에서 데이터 보존.
- [ ] 단일·두 영역의 페이지·확대·회전·진행선·필기 복원.
- [ ] 그룹 안팎 다중 이동·라벨/레일 독립 정렬·빈 그룹 정리.
- [ ] 카운터·타임랩·연결 진행선의 저장·정확한 실행 취소.
- [ ] 수동 시간 추가·실행 중 추가·일시정지·재진입의 누계와 보고서/PDF 값 일치.

## 실제 환경
- [ ] 390·1024·1440px, 가로/세로, 7개 언어·키보드·팝오버·입력 편집.
- [ ] 마우스·터치의 선택·드래그·핀치·취소·화면 복귀.
- [ ] 생성 portable 직접 실행 및 실제 Android 태블릿.
- [ ] 요청된 GitHub 반영은 워크플로·공개 화면으로 확인.

미확인 항목을 코드 검사나 빌드 결과로 완료 처리하지 않는다. 검증 결과는 해당 작업 보고에 기록하고 이 문서는 점검 목록으로 유지한다.
