- [ ] 차트 행 인식·보정·취소·카운터 ±·복원·수동 중지/재개·회전.
- [ ] 텍스트·구간 강조 선택/이동·편집, 생성 한도·실행 취소·분할 페이지 공유.
- [ ] 썸네일 선택 그룹 생성·다중 이동·빈 그룹 정리·라벨/레일 독립 정렬.
- [ ] 오늘 시간·수동 추가·측정 저장·날짜 경계·카운터 타이머 시작 설정.
- [ ] 보고서 치수·게이지·바늘·공유·PDF와 저장 누계 일치.
- [ ] 내부 저장·백업 입력 호환과 기존 데이터 보존.

- [ ] 390·1024·1440px, 가로/세로, 단일/두 영역의 맞춤 배율·빠른 전환·확대 정밀 렌더.
