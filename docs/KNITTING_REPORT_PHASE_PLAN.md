# 보고서·작업 기록 구현 메모

## 데이터·화면
- 보고서는 문서 ID·보고서 ID로 관리하며 제목·실·바늘·게이지·치수·사진·메모·수정사항을 저장한다.
- 표지 제목은 인라인 편집한다. 공유 항목은 선택·미리보기 후 문구·이미지·PDF로 출력한다.
- 날짜별 작업 사진, 로컬 수정 후보의 사용자 검토, 개인 기록의 상세 입력을 유지한다.
- Viewer 시간 표시와 보고서 카드는 공통 작업 기록 패널을 사용한다.
- 패널은 저장된 총 누계·최신순 일별 기록을 보여 주고 날짜를 펼치면 세션·세션 미상 시간·메모를 표시한다.
- 인라인 날짜·시간·분 입력으로 수동 추가한다. 통계 버튼에서 일별·주간·월간 그래프를 연다.
- 수동 추가와 측정 세션은 구분하며 보고서·홈·PDF는 같은 저장 누계를 사용한다.

## 확인
추가·취소·실패·중복 저장, 과거 날짜·같은 날짜 합산, 실행 중 추가 후 일시정지, 재진입·메모 복원·출력 값 일치를 검사한다. 저장 중 닫기를 잠그고 실패 입력을 유지한다.
