# 보고서·작업 기록 메모

## 보고서
- 목록은 프로젝트와 같은 레이아웃·검색·상태·정렬·보기 체계를 사용하며 보고서 하나를 카드 하나로 표시한다.
- 문서 ID·보고서 ID로 제목·실·독립 바늘·게이지·완성 치수·사진·메모·수정사항을 저장한다.
- 게이지는 무늬·세탁 전후 실측·단위, 바늘은 브랜드·mm/US/일본 표기를 지원한다.
- 새 보고서는 가슴둘레·총장 두 행으로 시작한다. 치수 선택과 행을 동기화하고 값이 있는 행 해제는 확인한다. 이름 수정 취소·빈 입력은 원래 이름을 복원한다.
- 공유 항목을 선택·미리보기하고 문구·이미지·PDF로 출력한다. 원본 값과 기존 보고서를 보존한다.

## 시간·타임랩
- Viewer 시간·보고서 카드는 공통 작업 기록 패널을 연다. 총 누계·최신순 날짜·세션·세션 미상 시간·메모와 일/주/월 통계를 제공한다.
- 날짜·시간 0~9999·분 0~59를 인라인 입력하며 합계 1분 이상을 추가한다. 저장 중 중복·취소·닫기를 잠그고 실패하면 입력을 유지한다.
- 표시 타이머는 오늘 저장 합계와 현재 측정을 반영한다. 수동 추가는 측정을 이어 가며 실제 측정 세션을 만들지 않는다.
- 측정은 일시정지·저장하고 나가기·날짜 경계에서 ID로 중복 없이 저장한다. 매초 표시는 저장하지 않는다.
- 타임랩은 같은 카운터·Viewer 세션의 클릭 시각 차이이며 첫 기록은 0이다. 작업시간 누계를 증감하지 않는다.
- 카운터 타이머 시작은 자동/처음 한 번 확인/독립 모드를 저장한다. 기본은 처음 한 번 확인이다.
- 프로젝트 카드·보고서·PDF는 저장된 같은 누계를 사용한다. 직접 작성한 작업시간 메모는 자동 누계와 별개다.
