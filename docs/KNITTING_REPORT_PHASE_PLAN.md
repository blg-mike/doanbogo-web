# 마지막 페이지 뜨개보고서 Phase Plan

작성일: 2026-10-04 · 상태: 구현·자동 검사·portable 빌드 완료. Chrome/Edge 직접 실행 확인은 미수행.

## 실행 기준

별도 요청 전까지 앱은 `doanbogo-web/portable/index.html`을 Chrome 또는 Edge에서 직접 연다. 소스 변경 후 `npm run build:portable`로 갱신한다. 저장·백업 버전은 IndexedDB v4, `.doanbogo` v7이며 이전 백업 v1~v6도 가져온다.

## 확정 사항

- 보고서는 PDF별 한 개이며 마지막 썸네일 뒤에 둔다. 마지막 PDF 페이지에서 다음으로도 열고, 보고서에서 PDF로 돌아오면 보고서 진입 전 페이지·보기 상태를 복원한다.
- 프로젝트명은 PDF 파일명으로 시작하고 나머지 정보는 빈 상태로 둔다. 입력은 페이지 안에서 바로 편집하고 자동 저장한다.
- `report.md`의 7개 항목과 첨부 이미지를 참고해 구성한다. 도안 치수는 한 번 저장하고 도안 정보와 완성 비교에서 공유한다.
- 사진은 브라우저 안에서 축소해 JPEG data URL로 저장한다. 백업에 함께 포함한다.
- PDF는 원본과 별도로 바로 다운로드한다. A4 세로 페이지를 캔버스 이미지로 만들어 출력하므로 글자 검색·복사는 지원하지 않는다. 빈 항목은 생략하고 긴 내용은 여러 쪽으로 나눈다.

## 구현 단계

1. **진입·저장:** PDF 꼬리 썸네일과 마지막 페이지 다음 동작을 연결하고, IndexedDB v4에 보고서를 추가한다.
2. **7개 항목 편집:** 프로젝트·도안·실·바늘/부자재·게이지·치수/변형·완성 후기를 페이지 안에서 편집한다. 반복 행과 사진 추가·삭제를 지원한다.
3. **PDF 출력:** 한글과 사진을 이미지 기반 다중 페이지 PDF로 다운로드한다. 표와 긴 내용의 페이지 경계를 처리하고 쪽 번호를 표시한다.
4. **호환·문서:** PDF 복사·삭제와 백업 v7에서 보고서를 함께 복사·삭제·보존하며 README에 portable 직접 실행을 명시한다.

## 완료 검증

- `npm run typecheck`, `npm run lint`, `npm test`(17개 통과)가 통과한다.
- portable 단일 HTML을 갱신한다.
- Chrome/Edge에서 PDF의 마지막 썸네일·다음 버튼, 보고서 복귀, 자동 저장, 사진 업로드, 다중 페이지 PDF, PDF 복사·삭제, v1~v7 백업 호환을 확인한다.
- 정적·자동 검사 결과와 portable 파일을 브라우저에서 직접 연 결과를 구분해 기록한다.

## 구현 상태

현재 소스에 보고서 편집 화면, 이미지 PDF 생성, IndexedDB v4 저장, 백업 v7 호환을 추가했다. 타입 검사·린트·17개 테스트와 portable 단일 HTML 빌드가 통과했다. 실행 도구가 `file://` 페이지를 열지 않아 Chrome/Edge 직접 열기와 실제 사진·PDF 화면 QA는 확인되지 않았다.
