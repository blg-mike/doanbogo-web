# 편집·썸네일 그룹 메모

## 편집
- 펜·형광펜은 선택과 필기 설정을 함께 켜고 첫 Canvas 조작에서 설정만 닫는다.
- 승인 10색·2행×5열을 사용한다. 펜/형광펜 각 100개·텍스트 50개·구간 강조 10개를 페이지별 신규 생성 한도로 적용한다.
- 생성 시작·반영 때 최신 데이터를 검사하고 분할 보기의 같은 페이지도 한도를 공유한다. 기존 객체·과거 색상은 보존하며 삭제·실행 취소 후 추가할 수 있다.
- 텍스트는 탭으로 인라인 편집하고 드래그로 이동한다. 구간 강조·이동 도구는 첫 탭으로 강조 영역을 선택하고 다음 드래그로 이동하며 모서리로 크기를 조절한다.
- 스타일은 팔레트→이름→전체 폭 슬라이더를 사용한다. 팝업은 화면 안에 배치하고 바깥 클릭·Escape로 닫는다.
- 진행선 hit target은 겹치는 개체보다 우선한다. 입력창·팝업과 원본 밖 도구 입력은 유지한다.

## 그룹
- 페이지 선택·그룹 펼침·드래그 대상을 분리한다. 선택 목록은 드래그 시작 때 확정하고 모든 드롭 경로에 같은 목록을 전달한다.
- 반투명 썸네일·삽입/드롭 표시·가장자리 자동 스크롤을 제공한다. 그룹 밖 드롭은 소속 해제, 빈 그룹은 삭제다.
- 마지막 선택 썸네일 위 그룹 추가는 팝업을 연 시점의 선택을 묶고 가장 앞선 레일 위치에 삽입한다. 취소·실패는 선택·입력을 보존한다.
- 라벨 메뉴는 이름·순서·해지다. 라벨 순서와 레일 그룹 위치는 450ms 롱프레스로 독립 정렬한다. 롱프레스 전 8px 초과 이동은 스크롤로 처리한다.
- 소속·`thumbnailGroups`·`thumbnailRailOrder`를 함께 저장한다. 성공 후 선택을 해제하고 새 그룹을 자동 펼치지 않는다.
- 드래그 좌표·자동 스크롤은 ref·단일 프레임 루프로 관리하고 실제 대상 변경만 UI에 반영한다. cancel·캡처 해제·종료는 드래그를 취소·정리한다.

## 터치·확인
Viewer의 비편집 선택·기본 메뉴·세로 스크롤 전파를 차단하되 입력 편집과 패널 내부 스크롤을 유지한다.
관련 소스: `Viewer.tsx`, `PdfPage.tsx`, `viewerInteraction.ts`, `annotationLimits.ts`, `pageManagement.ts`.
한도 경계·취소·겹침·다중 선택·그룹 안팎 이동·독립 정렬·저장 실패·실행 취소·복원을 확인한다.
