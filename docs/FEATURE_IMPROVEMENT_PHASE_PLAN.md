# 편집·썸네일 그룹 구현 메모

## 편집
- 펜·형광펜 버튼은 도구와 필기 설정을 함께 켜고 첫 Canvas 조작에서 설정을 닫는다.
- 색상은 10색·2행×5열. 펜/형광펜 각 100개, 텍스트 50개, 구간 강조 10개를 페이지별 신규 생성 한도로 적용한다.
- 텍스트 탭은 인라인 편집, 드래그는 이동. 구간 강조는 전용 도구 선택 → 영역 선택 → 다음 드래그로 이동한다.
- 스타일 팝업은 색상·슬라이더를 같은 양식으로 표시하고 바깥 클릭·Escape로 닫는다.

## 그룹
- 선택 목록을 드래그 시작에 확정하고 모든 드롭 경로에서 같은 목록을 사용한다.
- 반투명 썸네일·드롭 표시와 가장자리 자동 스크롤을 제공한다. 그룹 밖 드롭은 소속 해제, 빈 그룹은 자동 삭제다.
- 상단 라벨과 레일 그룹 위치를 독립 정렬한다. 450ms 롱프레스·8px 이동 기준과 취소 정리를 유지한다.
- `thumbnailGroups`, `thumbnailRailOrder`를 기존 Viewer 저장 경로로 함께 저장한다.

## 수정·확인
`Viewer.tsx`, `PdfPage.tsx`, `viewerInteraction.ts`, `annotationLimits.ts`, `pageManagement.ts`의 실제 관련 경로를 확인한다. 페이지별 한도·다중 선택·터치 충돌·저장 실패·실행 취소·재진입·백업을 검사한다.
