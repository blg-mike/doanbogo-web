V. 자주 묻는 질문005 / 006

시작 전에 확인해 보세요

자주 묻는 질문

어떤 뜨개도안을 사용할 수 있나요?

PDF 도안을 열 수 있고, 종이 도안은 사진 도안 폴더로 만들 수 있어요. 나만의 뜨개 차트를 직접 그릴 수도 있습니다.

도안과 작업 내용은 어디에 저장되나요?

도안과 작업 데이터는 브라우저 로컬 저장소에 저장됩니다. 자동 기기 간 동기화는 제공하지 않으므로, 기기를 옮길 때는 작업 파일을 내보내어 백업하고 가져오세요.

회원가입이나 로그인이 필요한가요?

현재 앱에는 가입·로그인 절차가 없습니다. 브라우저에서 앱을 열어 도안을 추가하면 바로 시작할 수 있어요.

태블릿과 휴대폰에서도 쓸 수 있나요?

모바일·태블릿 화면에 맞춰 배치되는 웹 앱입니다. 브라우저에서 열어 현재 기기에 맞는 화면으로 사용할 수 있습니다.

도안을 열고 작업을 기록하는 방법

도안을 가져온 뒤 진행 위치, 단수, 시간을 기록하고 다음에 이어서 뜹니다.

  1. 01

    도안 가져오기

    프로젝트에서 ‘PDF 가져오기’를 누르거나 ‘사진 도안 만들기’에서 사진을 선택합니다.

  2. 02

    진행선 표시하기

    뷰어에서 ‘진행선 시작’을 선택하고 차트에서 작업 중인 줄에 선을 놓습니다.

  3. 03

    카운터 맞추기

    카운터를 추가해 현재 단수를 입력합니다. 진행선과 연결하면 단수를 바꿀 때 위치도 함께 이동합니다.

  4. 04

    작업 시간 재기

    뷰어의 타이머를 시작하거나 일시정지합니다. 저장된 기록은 프로젝트의 작업 기록에서 확인합니다.

  5. 05

    저장하고 다시 열기

    작업 위치와 메모는 브라우저에 저장됩니다. 기기를 옮기기 전에는 프로젝트 백업을 내보내고 새 기기에서 가져옵니다.

도안에 맞춰 골라 쓰는 기능

자주 쓰는 작업을 도안 옆에서

사진 도안 정리, 두 영역 보기, 뜨개 기록을 실제 작업 순서에 맞춰 사용할 수 있습니다.

01

사진 도안: 페이지를 모으고 순서를 정리해요

‘사진 도안 만들기’에서 여러 장을 가져와 한 도안으로 구성합니다. 페이지 순서를 확인하고 필요하면 사진을 추가해 이어서 봅니다.

02

두 영역 보기: 두 페이지를 나란히 살펴봐요

뷰어에서 ‘두 영역 보기’를 선택합니다. 각 영역에서 페이지와 확대 위치를 따로 조작하고, 가운데 구분선을 움직여 화면 비율을 조정합니다.

03

뜨개 기록: 작업 시간과 메모를 돌아봐요

타이머 기록과 프로젝트 메모를 저장하면 프로젝트의 작업 기록에서 날짜별 작업 시간과 남겨 둔 내용을 확인할 수 있습니다.

저장과 사용 환경

자주 묻는 질문

데이터 저장, 백업, 브라우저와 기기 사용에 관해 안내합니다.

내 도안과 작업 내용은 어디에 저장되나요?

도안과 작업 데이터는 현재 사용 중인 브라우저의 기기 내 저장소에 보관됩니다. 계정이나 자동 기기 간 동기화는 제공하지 않습니다.

브라우저 저장을 사용할 수 없으면 어떻게 되나요?

저장소를 사용할 수 없는 환경에서는 임시 저장으로 동작할 수 있으며, 이 경우 브라우저를 닫으면 데이터가 유지되지 않을 수 있습니다. 화면에 표시되는 저장 상태를 확인하세요.

백업과 복원은 어떻게 하나요?

프로젝트 화면의 백업 내보내기로 작업 파일을 저장하고, 복원할 때는 가져오기를 사용합니다. 백업 파일은 별도 위치에 보관하세요.

브라우저 데이터를 지워도 되나요?

사이트 데이터나 브라우저 저장 공간을 지우면 도안과 작업 기록이 삭제될 수 있습니다. 먼저 백업을 내보내세요.

기기나 브라우저, 사이트 주소를 바꾸면 기록이 따라오나요?

브라우저·기기·사이트 주소가 바뀌면 저장소가 달라져 자동으로 이어지지 않습니다. 기존 환경에서 백업을 내보내고 새 환경에서 가져오세요.

어떤 기기에서 사용할 수 있나요?

브라우저에서 실행되는 웹 앱이며 화면 크기에 따라 배치가 바뀝니다. 동작은 브라우저와 기기 환경에 따라 달라질 수 있으므로, 중요한 작업은 먼저 백업하고 사용 중 저장 상태를 확인하세요.

회원가입이 필요한가요?

현재 문서화된 기본 기능은 계정을 만들지 않고 사용할 수 있습니다.
