# KnitPeek プライバシーポリシー

- サービス名: **KnitPeek**（韓国語名: **니트피크**）
- ウェブサイト: **https://knitpeek.pages.dev**
- 施行日: **2026年11月6日**
- 運営者: **KnitPeek**
- 個人情報に関するお問い合わせ: **knitpeek.cs@gmail.com**

## 1. 概要

**KnitPeek**（以下「運営者」）はプライバシーを尊重し、適用されるデータ保護法令の遵守に努めます。KnitPeek は編み図を閲覧し、個人のプロジェクト記録を管理する**ローカル優先**のウェブアプリケーションです。

基本機能の利用にアカウント登録は必要ありません。取り込んだPDF・写真の編み図、プロジェクト、作業記録はブラウザー内に保存され、KnitPeek が管理するサーバーにアップロードされたり、KnitPeek アカウントに同期されたりしません。これとは別に、KnitPeek のホスティングに伴い、Cloudflare がウェブサイトへのリクエスト情報を処理する場合があります。

## 2. 情報の種類と利用目的

| 区分 | データ | 目的・方法 |
| --- | --- | --- |
| 端末内に保存されるプロジェクトデータ | 取り込んだPDF・写真、プロジェクト名・タグ、表紙画像、注釈、進行線、チャート、カウンター・タイマーの記録、レポート、メモなど | ブラウザー内で閲覧、編集、復元、書き出しを行います。取り込んだファイルや作業記録はKnitPeekのサーバーにアップロードされません |
| 端末内の設定 | 言語、ビューア設定、プロジェクトの状態など | 端末で設定を保持する。初期表示言語の判定にブラウザーの言語設定を利用する場合がある |
| ウェブサイトへのアクセス情報（ホスティング事業者） | 訪問者のIPアドレス、リクエストURL・時刻、ブラウザー・端末およびトラフィック経路に関する情報 | Cloudflare Pages がウェブサイトの提供・保護のために処理する場合があります。詳しくは[Cloudflare プライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご確認ください。 |
| Cloudflare Web Analytics の測定情報 | ページパス・参照元、ブラウザー・端末のカテゴリ、ページビュー・訪問数、ページ読み込みのパフォーマンス指標 | Cloudflare Web Analytics のビーコンをブラウザーで実行し、ウェブサイトの利用状況とパフォーマンスを測定します。Cloudflare は Web Analytics が訪問者の個人データを収集・利用しないと説明しています。[Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/) |

**重要:** 端末だけに保存された編み図やメモに個人情報が含まれていても、運営者がその内容を受領または閲覧できるとは限りません。利用者が自ら書き出しまたは共有した情報は、選択した送信先で取り扱われる場合があります。

## 3. 保管期間

1. **ローカルのプロジェクトデータ:** 利用者が削除するか、ブラウザーまたは端末が保存を停止するまで、該当する端末・ブラウザーの保存領域に残る場合があります。運営者が別途ユーザーファイルのデータベースを保有しているわけではありません。
2. **端末内の設定:** 削除またはリセットされるまで、関連するブラウザー保存領域に残る場合があります。
3. **Cloudflare Pages と Web Analytics の情報:** Cloudflare は、IPアドレス、トラフィック経路、システム構成および関連するリクエスト情報を処理する場合があります。Web Analytics の測定情報も Cloudflare の方針に従って処理・保管され、運営者はその保管期間を定めません。詳しくは[Cloudflare プライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご確認ください。
4. **お問い合わせ:** 利用者が自発的に送信したメールアドレスと問い合わせ内容は、回答および関連対応に必要な期間だけ保管し、法令に基づく保存義務がある場合を除き、目的達成後に削除します。

## 3A. 欧州のプライバシー法が適用される場合の法的根拠

欧州経済領域（EEA）などで関連法令が適用される場合、メールでのお問い合わせへの対応は、利用者の依頼に応じるなど、状況に適した法的根拠に基づきます。法令上の保存義務がある情報は、その義務に従って保管します。

## 4. 第三者への開示、サービス提供者、国外処理

1. KnitPeek は、取り込まれたPDF・写真の編み図やローカルの作業記録を運営者のサーバーへ送信せず、広告主などの第三者にも販売しません。
2. **ウェブサイトのホスティングと分析:** サイトは Cloudflare Pages で提供されます。Cloudflare Web Analytics のスクリプトがページビュー、訪問数、参照元およびパフォーマンスを測定し、その測定情報を Cloudflare に送信します。詳しくは[Cloudflare プライバシーポリシー](https://www.cloudflare.com/privacypolicy/)と[Web Analytics](https://developers.cloudflare.com/web-analytics/about/)をご確認ください。
3. ブラウザー内だけに保存された編み図や作業記録はKnitPeekに送信されません。ホスティング事業者によるリクエスト処理と、ローカルファイルの内容は別のものです。

4. 運営者が新たな個人情報の提供先、処理委託先、国外移転を導入する場合、適用法令に従って説明し、必要な同意を取得します。

## 5. Cookie、ブラウザー保存、類似技術

1. KnitPeek はプロジェクトや設定を端末に保存するため、IndexedDBなどの**ブラウザー保存機能**を使用します。ブラウザー保存自体は、内容をサーバーへアップロードする仕組みではありません。
2. KnitPeek は広告目的の追跡Cookieを使用していません。サイト利用とパフォーマンスの測定には、Cookieを使用しない Cloudflare Web Analytics のスクリプトを使用します。Cloudflare は Web Analytics が訪問者の個人データを収集・利用しないと説明しています。言語とサービス設定はブラウザー内に保存されます。
3. ブラウザー設定からCookieやサイトデータを削除・制限できます。サイトデータの削除により、保存済みの編み図や作業記録も消える場合があります。必要な原本ファイルと出力したレポートを別に保管しているか、先に確認してください。
4. ローカルデータは保存したウェブサイトのアドレスとブラウザープロファイルに紐づき、別のアドレス、ブラウザー、プロファイルに自動共有・移行されません。サイトデータを削除する前に必要な資料を別途保存してください。

## 6. 書き出し、共有、外部ウェブサイト

1. 文書、レポート、プロジェクト記録を自分で書き出しまたは共有すると、選択した情報が指定した保存先や共有サービスへ移動する場合があります。
2. 本サイトのBuy Me a Coffeeリンクや編み図のURL・QRコードなどの外部リンクを開くと、第三者のサービスに移動します。アクセス情報は各サービスのプライバシーポリシーに従って処理されます。
3. これらは利用者の選択による操作であり、KnitPeek が編み図の原本を自動で公開またはアップロードすることを意味しません。

## 7. データの削除

1. 利用者は、利用可能な削除機能またはブラウザーのサイトデータ削除を使ってローカルデータを削除できます。別途保存したバックアップは利用者自身で管理・削除してください。
2. 運営者が問い合わせ内容などの個人情報を実際に保有する場合、利用目的が終了し、法的保管義務がないときに、合理的に復元が困難な方法で削除します。
3. ホスティングに伴いCloudflareが処理するアクセス情報は、Cloudflareの方針と手続きに従って処理・削除されます。

## 8. 本人の権利と行使方法

1. 適用法令に従い、利用者は運営者が実際に取り扱う個人情報の開示、訂正、削除、処理停止などを請求できます。
2. 個人情報の開示・訂正・削除・利用停止の請求および関連する苦情は、KnitPeek チーム（knitpeek.cs@gmail.com）へお送りください。適用される法令に従って対応します。
3. プロジェクトデータが利用者の端末にしか存在しない場合、運営者はそのデータを遠隔で閲覧、訂正、復元、削除できません。利用者自身の端末とサービスのローカル機能で管理してください。
4. EU/EEAのGDPRなどが適用される場合、法律上の条件に従い、処理制限、データ移転、異議申立て、監督機関への苦情申立てなどの権利を行使できる場合があります。

## 9. セキュリティ対策

1. 本サービスは、取り込んだ編み図やプロジェクト記録を基本的にブラウザー内で処理し、運営者管理サーバーへの不要な送信を減らすよう設計されています。
2. ウェブサイトの通信には、対応し設定されている場合、HTTPSを使用します。
3. 利用者は端末のロック、ブラウザーの更新、書き出したバックアップの安全な保管などにより、ローカルデータを保護してください。
4. ローカル優先の保存は、自動暗号化や完全なデータ安全性を保証するものではありません。

## 10. 子どものプライバシー

KnitPeek は特定の年齢層だけを対象とするサービスではありません。文書化された基本サービスでは、アカウントを作成せず、生年月日も収集しません。子どもの個人情報を扱う機能を導入する場合、適用法令に必要な保護者の同意などの措置を実施します。

## 11. 本ポリシーの変更

運営者は、サービス構成または個人情報の取り扱いが変更された場合、本ポリシーを改定します。重要な変更と施行日はサービス内でお知らせし、法令上必要な追加通知や同意の手続きを行います。
